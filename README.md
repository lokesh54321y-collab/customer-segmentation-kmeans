## Conclusion

This project used K-Means clustering to divide mall customers into meaningful
groups using age, annual income, and spending score.

The optimal number of clusters was selected using the silhouette score and
the elbow method. The final model identified customer groups with different
income and spending patterns.

High-value customers had relatively high annual income and high spending
scores. This segment can be targeted with VIP programs, premium product
recommendations, and loyalty rewards.

Careful affluent customers had high income but lower spending. The business
can target this segment using personalized promotions and product offers.

The analysis shows that customer segmentation can help businesses make more
targeted marketing decisions instead of treating every customer in the same way.
